## Tuturium 1.3.16

- Estimasi durasi perpustakaan mendukung seluruh rentang 0,5–4× tanpa batas 1.000 menit.
- Sorotan PDF pada kata aktif, kalimat, dan kata yang dipilih; menu Baca/Salin horizontal.
- Ikon pin pada folder dan dokumen; opsi folder untuk tampilan, urutan, pengelompokan tanggal.
- Panel tambah dengan Kamera, Foto, File, Buat Folder, tautan, teks, dikte, dan pemilih penyimpanan/cloud Android. Impor dari folder otomatis masuk ke folder tersebut. Folder masih datar.
- Pencarian pembaca berada di atas keyboard tanpa padding IME ganda.

## Tuturium 1.3.15

- Tiga preset kecepatan 0,8× / 1× / 1,2×, tanpa tombol Selesai; slider 0,5×–4×.
- Sakelar PDF/Teks lebih ringkas; tekan lama teks untuk Baca/Salin di kedua mode.
- Lapisan posisi kata PDF disiapkan per halaman, dengan Android PDF API 35 dan OCR bitmap sebagai fallback.
- Penguatan audio sesi Google TTS dan Supertonic hingga +9,5 dB, dengan kompresi platform dan kontrol volume perangkat tetap berlaku. Hasil aktual bergantung pada dukungan OEM dan output audio.

## Tuturium 1.3.14

- Panel laju 0,5×–4× bergaya Speechify, tanpa kunci; kenaikan otomatis tetap opsional.
- PDF tidak lagi dibatasi 1.500 halaman atau dua juta karakter; ekstraksi satu lintasan. Batas ukuran berkas 100 MB tetap untuk keamanan perangkat.
- PDF mengikuti tema gelap melalui filter rendering; tekan lama kata dari lapisan teks untuk Baca atau Salin. PDF pindai tanpa lapisan teks masih menggunakan mode Teks.
- Sakelar PDF/Teks mengambang di atas dokumen tanpa bilah latar lebar.
- Reader dibuka dalam keadaan jeda; Supertonic yang terpasang menyiapkan hingga dua potongan awal ke cache tanpa memainkan audio.
- Pustaka Suara di profil; penguatan narasi offline adaptif dengan soft limiter, tanpa memaksa volume sistem.

## Tuturium 1.3.13

- Mode PDF menggulir halaman asli secara vertikal. Sakelar PDF/Teks lebih ringkas dan narasi tetap dapat mengikuti halaman yang dibaca.
- Panel kecepatan memiliki penggeser vertikal, tombol ±, pilihan cepat, dan perkiraan waktu tersisa. Semua laju 0,5×–4× dapat digunakan.
- Kecepatan otomatis naik 0,05× setiap 600 kata yang selesai diputar, hingga 4×. Kecepatan awal dapat disetel kapan saja.

# Tuturium v1.2.0

- Menu perpustakaan dengan ikon dan pilihan tampilan daftar, kotak besar/kecil, urutan terbaru/tanggal impor/abjad, kelompok format, dan pilih beberapa.
- Menu file sebagai panel bawah: berbagi salinan TXT, sematkan, baca nanti, putar berikutnya, antrean mendengarkan, pilih, pindahkan, ubah nama, status offline, dan hapus.
- Folder dapat dibuat melalui panel bawah serta disematkan, diubah nama, atau dihapus tanpa menghapus isinya.
- Pencarian langsung pada header perpustakaan, dengan filter hasil seketika.
- Tampilkan persentase kemajuan beserta perkiraan menit tersisa berdasarkan jumlah kata, posisi, dan kecepatan TTS. Buku lama dimigrasikan tanpa menghapus data.
- Penyimpanan & Data menampilkan ukuran lokal sebenarnya (dokumen, database, dan cache) dengan pembersihan cache yang tidak menyentuh buku.
- Rilis tetap menggunakan ARM64, OCR dan TTS offline, dan signing certificate yang sama.
